# ScreenHalo website

The website for [ScreenHalo](https://screenhalo.si/), a native macOS app for compatible USB LED strips.

The app source and releases are maintained separately in [ArneKorsika/ScreenHalo](https://github.com/ArneKorsika/ScreenHalo).
